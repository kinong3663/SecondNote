# 秒记卡 · 演示录屏素材（剪辑用）

按 `秒记卡/演示脚本.md` 的动线录的**原始素材**，没有叠加任何标题、字幕、贴纸——那些交给剪辑。
画面里能直接用的东西只有一样：**可见光标 + 点击涟漪**（浏览器录屏本身不录系统光标，所以录制时注入了一个）。

## 一、素材规格

| 项 | 值 |
|---|---|
| 分辨率 | 1920 × 1080 |
| 编码 | H.264 MP4（Premiere / 剪映 / FCP 都能直接拖） |
| 帧率 | 约 25fps（浏览器录屏原始帧率） |
| 音轨 | **没有声音**，旁白后期加 |
| 光标 | 白色箭头 + 点击时的蓝色涟漪，是真鼠标位置 |
| 数据 | 真实保利威点播视频 + 平台智能字幕（3472 条）+ 真实接口 + 真实模型调用 |

教师端那一屏的数字是真的：**11 张卡 / 4 位学生**＝演示前按脚本灌的 8 张（`node scripts/seed-notes.mjs`）＋ 本轮现场点下去的 3 张。

## 二、两套文件，优先用「精简」

| 目录 | 说明 |
|---|---|
| `剪辑素材/0X-*.mp4` | 原始：每段都从「打开页面」开始，含 8–15 秒加载/缓冲 |
| `剪辑素材/精简/0X-*.mp4` | **推荐**：已裁掉开头的加载，06 段还把中间的「视频加载中」跳切掉了 |
| `剪辑素材/完整版.mp4` | 8 段原始顺接（3:44） |
| `剪辑素材/精简/完整版.mp4` | 8 段精简顺接（2:09） |
| `剪辑素材/静帧/*.png` | 8 张满分辨率静帧，可当封面/标题页底图 |
| `剪辑素材/beats.json`、`剪辑素材/精简/beats.json` | 每个动作的秒数（`tInClip` 是素材时间轴上的秒数） |

## 四、剪辑建议

- **不要给播放器画面加暗角/滤镜**：整片的说服力就在"这是真视频、真字幕"。
- 每段开头可以留 0.5 秒静止再起字幕，动作不至于贴着画面边缘。
- 01 段三张卡的顺序＝脚本三个痛点（没听懂 / 要照做 / 有疑问），配旁白时可以对着一一报数。
- 05 段的等待是唯一"不好看"的地方，加速或跳切都行；生成结果里「下一节课可以这样改」那三条是最值得给特写的。
- 06 段可以在 9.7 秒点击处加一个 0.3 秒的定格 + 音效，强调"跳回同一秒"。
- 静帧 `04-教师端热力图.png`、`05-AI复盘.png` 适合做标题页/章节页底图（暗色滤镜后压字）。

## 五、重录方法

```powershell
cd 秒记卡
npm start                                       # 服务在 8787
node ../scripts/seed-notes.mjs --clear          # 清空旧卡
node ../scripts/seed-notes.mjs                  # 灌 8 张，教师端才有热力图
Remove-Item work/summaries/vod_bfcb278e7a88e2d51e23ba453596ddf2_b.json   # 想让 AI 重新生成就删缓存

cd ../demo-video
node record.mjs                                 # 录全部 8 段 → raw/segments/*.webm + beats.json
node record.mjs 06                              # 只补录某一段（会复用上一轮的学生端本地状态）
node make-state.mjs                             # 补录前若 storage-state.json 丢了，用它从服务端重建
node calibrate-beats.cjs                        # 重算每个动作在成片时间轴上的秒数
node trim.mjs                                   # 重新生成精简版
```

录制脚本 `record.mjs` 的要点：Playwright 驱动真实 Edge 无头浏览器、1920×1080、注入可见光标、
鼠标分步移动后再点击；学生端和教师端全部走真实页面与接口，没有任何 mock。
