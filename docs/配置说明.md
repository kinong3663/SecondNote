# 秒记卡 · 环境与密钥配置说明

> 回答三个问题：**要哪些参数**、**从哪儿拿**、**别人拿到代码后怎么改**。
> 只想先把项目跑起来 → 看根目录 [`../README.md`](../README.md) 的「5 分钟跑起来」。

> 所有参数只走服务端环境变量；浏览器里永远看不到密钥。

---

## 0. 一分钟版

```powershell
cd 秒记卡
Copy-Item .env.example .env.local     # 复制模板
notepad .env.local                    # 填 5 个必填（见下）
npm install
npm run demo                          # http://127.0.0.1:8787
```

必填 5 个（`POLYV_DEMO_VIDEO_ID` 建议一起填）：

```dotenv
POLYV_APP_ID=             # 直播 AppID
POLYV_APP_SECRET=         # 直播 AppSecret
POLYV_VOD_USERID=         # 点播 userid
POLYV_VOD_SECRETKEY=      # 点播 secretkey
POLYV_DEMO_CHANNEL_ID=    # 你的频道号，例如 4711207

# 建议填：不填就用该频道点播列表第一条
POLYV_DEMO_VIDEO_ID=
```

## 1. 全部参数一览

模板文件：`秒记卡/.env.example`（仓库根目录还有一份给 `scripts/*.mjs` 用，内容一致）。

| 变量 | 必填 | 示例 | 从哪里拿 | 不填会怎样 |
|---|---|---|---|---|
| `POLYV_APP_ID` | ✅ | `fwdxxxxxxx`（后台可见） | 直播后台 → 设置 → **开发者信息** | `/api/health` 返回 `polyvConfigured:false`，页面退回「演示数据」并明确标注 |
| `POLYV_APP_SECRET` | ✅ | 32 位十六进制 | 同上（点「显示」） | 签名算不对，接口返回 sign 错误，视频库为空 |
| `POLYV_VOD_USERID` | ✅ | 一串数字 | **点播**后台 → 设置 → 开发者信息（注意不是登录账号） | 点播接口全 404，视频空间空，控制台 `点播列表不可用` |
| `POLYV_VOD_SECRETKEY` | ✅ | 32 位十六进制 | 同上 | 同上 |
| `POLYV_DEMO_CHANNEL_ID` | ✅ | 你的频道号，如 `4711207` | 观看页地址里的数字：`live.polyv.cn/watch/<数字>` | 学生端直接显示「还差一步：配置频道号」引导页（**不会**静默打开别的频道）；`/api/health` 的 `channelId` 为空 |
| `POLYV_DEMO_VIDEO_ID` | ⬜ 建议填 | `bfcb278e7a88e2d51e23ba453596ddf2_b` | 点播列表里每条视频的 `vid`；或调 `/v2/video/search-videos` 看返回 | 学生端**能用**（自动取该频道点播列表第一条，见 `videos.find(...) ?? videos[0]`）；但教师端默认复盘的视频会变成空标题 `vod:`、数字全 0，需要用户在左栏手动点一条课 |
| `POLYV_DEMO_SOURCE` | ⬜ | `vod` | — | 留空时按频道播放列表配置（`origin`）决定是点播还是录制 |
| `POLYV_VOD_PAGE_SIZE` | ⬜ | `50` | — | 默认 50 |
| `POLYV_DEMO_VOD_TITLE` | ⬜ | — | — | 点播库取不到标题时显示「点播视频」 |
| `LLM_PROVIDER` | ⬜ | `deepseek` / `dashscope` / `custom` | — | 默认按 key 自动推断 |
| `LLM_MODEL` | ⬜ | `deepseek-chat` / `qwen-plus` | 模型厂商文档 | 按 provider 取默认模型 |
| `LLM_API_KEY` | ⬜ | `sk-...`（也认 `DEEPSEEK_API_KEY` / `DASHSCOPE_API_KEY`） | 模型厂商控制台 | 教师端 AI 按钮变灰、提示「未配置模型 key」，只显示规则模板；**其余功能不受影响** |
| `LLM_BASE_URL` | ⬜ | `https://xxx/v1` | 自建/代理时填 | 用官方地址 |
| `PORT` | ⬜ | `8787` | — | 8787 |
| `ASR_PYTHON` | ⬜ | `python` | — | 本地转写兜底不可用（平台有智能字幕就不需要） |

> 学生端只读 `POLYV_DEMO_*` 与 `POLYV_VOD_*`；AI 那几个变量只影响教师端「用 AI 生成解读」。

## 2. 五个必填（+ 一个建议）分别怎么拿

**① 直播 AppID / AppSecret**
保利威直播后台 → 左侧「设置」→「开发者信息」。AppID 直接可见，AppSecret 需要点「显示」。
→ 用来调 `/live/v4/channel/basic/get`、`/live/v4/channel/record-file/list` 等（签名算法 MD5）。

**② 点播 userid / secretkey**
保利威**点播**后台 → 「设置」→「开发者信息」。`userid` 是接口签名里的用户 ID，不是手机号也不是登录名。
→ 用来调 `/v2/video/search-videos`、`/v2/video/{userid}/srt/list`（签名算法 SHA1，userid 必须进签名）。

**③ 频道号（必填）**
打开观看页，地址形如 `https://live.polyv.cn/watch/4711207`，斜杠后面那串数字就是。
留空不会白屏，但学生端会显示一张「还差一步：配置频道号」的引导页，告诉你填哪一行、频道号去哪抄——**不再静默兜底到某个演示频道**（早期版本会偷偷打开 8569582，那是别人的频道，很难排查）。

**④ 视频 vid（建议填，留空也能跑）**
点播列表里每条视频的 `vid`（形如 `bfcb278e7a88e2d51e23ba453596ddf2_b`）。
服务端取视频的逻辑是 `videos.find(v => v.videoId === wanted) ?? videos[0]`，所以留空就用**该频道点播列表的第一条**；代价是教师端默认复盘的 `videoKey` 会变成 `vod:`，标题空白、数字全 0，得在左栏手动点一条课。建议填上，学生端和教师端才会默认指向同一场。

## 3. 怎么确认配对了

```powershell
# ① 服务起来了吗、密钥读到没有
curl.exe -s http://127.0.0.1:8787/api/health
# 期望：{"ok":true,"polyvConfigured":true,"channelId":"4711207",...}

# ② 频道 + 视频库 + 字幕有没有拿到
curl.exe -s "http://127.0.0.1:8787/api/channel/4711207" | Select-Object -First 1
# 期望：videos 有 50 条（含 mediaUrl），transcript 有 3472 条 cue

# ③ AI 通道就绪没有（不打印 key）
curl.exe -s "http://127.0.0.1:8787/api/teacher/vod%3Abfcb278e7a88e2d51e23ba453596ddf2_b/summary?channelId=4711207"
# 期望：provider.ready = true
```

三条都过，就说明配置完整。

## 4. 换一场演示只要改三行

```dotenv
POLYV_DEMO_CHANNEL_ID=新的频道号
POLYV_DEMO_VIDEO_ID=新的视频 vid
POLYV_DEMO_VOD_TITLE=          # 可选
```

改完重启服务（`npm start`）即可。前端不写死频道号：服务端把配置注入 `window.__SECOND_NOTE_CONFIG__`，所以不用重新构建。

## 5. 密钥安全边界（写进代码的约束）

| 约束 | 原因 |
|---|---|
| 所有平台密钥只在 Node 进程里读 | 浏览器拿不到 appSecret / secretkey，签名也只在服务端算 |
| **禁止**把密钥写成 `VITE_*` | Vite 会把 `VITE_` 前缀的变量打进前端 bundle |
| `.env.local` 在 `.gitignore` 里 | 不会进版本库；`git ls-files` 里只有 `.env.example`（空值） |
| 交接包 zip 里含明文 `.env.local` | 那个包只给队友本地用，**不要上传到任何公开位置** |
| 泄露过的密钥必须轮换 | 一旦进过 git 历史或被发出去，改文件不算修好，要去后台重置 |

## 6. 上传 GitHub 前这次做了什么修正

| 问题 | 处理 |
|---|---|
| 诊断脚本（`scripts/check-vod.mjs`、`check-source-alive.mjs` 等）里**硬编码了真实的 appId / appSecret / 点播 secretkey**（历史提交 `d3a07f8`） | 全部改成必须从 `POLYV_*` 环境变量读取，缺了就报错退出；那几次提交的内容已从 git 历史重写 |
| `.env.example` 只有 3 个变量，别人 clone 不知道还要配点播、AI | 补全到 13 个常用变量（另有 `LLM_BASE_URL` / `ASR_PYTHON` 两个高级项写在注释里），每个都写了「从哪儿拿 / 不填会怎样」 |
| 没有一份集中说明 | 就是本文档，并在根 `README.md`、`秒记卡/README.md` 里链过来 |
| `demo-video` 里写死了本机 ffmpeg / Edge 路径 | 改成 `FFMPEG_PATH` / `FFPROBE_PATH` / `EDGE_PATH` 可覆盖，默认走 PATH |
| `remotion-demo/`（933MB）、`demo-video/成片/`、`痛点段-图片包/` 会被 `git add .` 带上去 | 都进了 `.gitignore`；`git add -A` 会加的文件从 3039 个降到 19 个 |
| 前端 `App.tsx` 里有 `DEFAULT_CHANNEL_ID = '8569582'`，没配频道号时**静默**打开别人的频道 | 已删除该兜底，改为「还差一步：配置频道号」引导页（`src/components/SetupScreen.tsx`）；`/api/health` 的 `channelId` 也返回空值 |

> ⚠️ **仍然建议你去保利威后台重置一次 AppSecret**：历史里出现过明文，重置最彻底；重置后把新的填进 `.env.local` 即可。

## 7. 别人 clone 之后怎么做（无密钥也能跑）

```powershell
git clone <repo> && cd 保利威黑客松

# ① 只看看界面（不需要任何密钥）
cd 秒记卡 && npm install && npm run demo
#   → 打开 http://127.0.0.1:8787 ，会看到「还差一步：配置频道号」的引导页
#     （配了频道号、但没配密钥时，才显示「演示数据」）

# ② 接自己的保利威账号
Copy-Item .env.example .env.local
# 填 §1 表格里的 5 个必填（+ 建议填 POLYV_DEMO_VIDEO_ID），重启 npm start

# ③ 想看教师端热力图有内容，先灌 8 张样例卡（走真实接口）
cd .. && node scripts/seed-notes.mjs

# ④ 想看 AI 复盘，再加 LLM_* 三个变量
```

## 8. 常见问题

| 现象 | 原因 | 改哪儿 |
|---|---|---|
| 学生端显示「还差一步：配置频道号」 | 没设 `POLYV_DEMO_CHANNEL_ID`（或格式不是纯数字） | `.env.local` 填频道号后重启；也可临时用 `?channelId=xxx` 打开 |
| 页面显示「演示数据」 | 有频道号、但直播 AppID/AppSecret 没读到 | `.env.local` 的 `POLYV_APP_*` |
| 视频空间空、控制台 `点播列表不可用` | 点播 userid/secretkey 缺失或错 | `POLYV_VOD_*` |
| 接口 404 且提到 sign | 点播签名漏了 `userid`，或路径写成 `videos` 复数 | 代码里的 `vodSign()`（已正确，说明是配置不对） |
| 教师端标题是空的 `vod:` | 没设 `POLYV_DEMO_VIDEO_ID`，取的是空 videoKey | 填上 vid（或从左栏点一条课） |
| 教师端 AI 按钮是灰的 | `LLM_API_KEY` 没进进程环境 | 填 `LLM_*` 后**重启**服务（不热重载） |
| 热力图很空、提示样本不足 | 卡片 < 12 张 | `node scripts/seed-notes.mjs` 灌样例后再点两张 |
| 改了 `.env.local` 不生效 | `npm start` 只在启动时读一次 | 重启进程 |
