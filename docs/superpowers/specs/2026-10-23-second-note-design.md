# 秒记卡设计规格

日期：2026-10-23

## 1. 产品目标

秒记卡是一款嵌入保利威定制观看页的学习辅助工具。观众在观看直播或回放时点击“记一下”，系统保存当前播放时间、附近字幕和一句内容摘要，生成可回看的笔记。点击笔记可以回到原视频位置。

参赛 Demo 的目标是在 60 秒内完整演示以下闭环：

1. 播放保利威频道内容。
2. 点击“记一下”生成笔记。
3. 查看按视频时间排列的笔记列表。
4. 刷新页面后笔记仍然存在。
5. 点击笔记时间戳回到对应画面。
6. 导出包含回看二维码的分享卡。

## 2. 范围

### 纳入首版

- 基于保利威官方观看页 SDK 的定制观看页。
- 播放器浮层“记一下”按钮。
- 当前时间、最近字幕和摘要的自动采集。
- 摘要的现场编辑。
- 笔记列表和视频时间轴标记。
- 点击笔记跳回原视频时间。
- 浏览器本地持久化。
- 单场直播的分享卡 PNG 导出。
- 桌面和移动端响应式布局。

### 不纳入首版

- 登录、账号体系和多设备云同步。
- 主讲人后台和班级管理。
- 多人协作编辑。
- 实时语音识别基础设施。
- 第三方大模型调用。
- 自动生成多页学习报告。
- 修改保利威频道配置、上传素材或创建正式菜单。

这些能力可以在参赛 Demo 验证后逐步接入，不应影响首版闭环。

## 4. 信息架构与交互

### 4.1 桌面端

- 页面左侧为主要播放器区域，右侧为可收起的“本节秒记”抽屉。
- 播放器右下角放置“记一下”悬浮按钮。
- 点击按钮后立即记录时间，并在抽屉顶部展开编辑卡。
- 编辑卡包含：
  - 视频时间戳
  - 字幕原文
  - 自动摘要输入框
  - 保存按钮
- 笔记保存到列表后，时间轴同步出现标记。
- 点击笔记卡片中的时间戳，调用播放器跳转到对应秒数。

### 4.2 移动端

- 播放器保持主导航位置。
- “记一下”为播放器底部悬浮胶囊按钮。
- 笔记编辑器从底部弹出，保存后可展开完整笔记列表。
- 分享卡以可预览、可下载的单列卡片呈现。

### 4.3 状态

- 未播放：按钮可点击，但提示先生成有效时间点。
- 正在播放：按钮显示当前时间。
- 生成中：按钮短暂显示“正在整理”。
- 成功：新增笔记卡片并出现轻提示。
- 字幕缺失：保存当前时间，摘要从视频标题或用户输入获得。
- 跳转失败：保留笔记并提示当前内容不支持定位。

## 5. 技术架构

### 5.1 组件

1. **前端观看页**
   - React/Vite 单页应用。
   - 使用 `@polyv/live-watch-sdk`。
   - 负责播放器、秒记浮层、笔记列表、分享卡和本地持久化。

2. **服务端适配层**
   - Node.js HTTP 服务。
   - 安全保存 AppSecret。
   - 生成保利威 API 签名。
   - 提供频道信息和演示转录文本。
   - 不向浏览器返回 AppSecret、推流密钥等敏感字段。

3. **字幕适配层**
   - 优先读取保利威回放字幕。
   - 无可读字幕时使用随项目提供的演示字幕。
   - 对每条字幕计算起止时间和纯文本，供前端按当前播放秒数查找。

4. **本地笔记仓库**
   - 以 `localStorage` 保存，按频道和视频 ID 隔离。
   - 存储结构包含稳定 ID、时间、字幕、摘要和创建时间。

5. **分享卡渲染器**
   - 使用浏览器 Canvas 生成 1080x1440 的 PNG。
   - 包含频道名、视频名、笔记摘要、时间戳和回看二维码。

### 5.2 数据流

```text
保利威 Open API
  -> 服务端签名与字段裁剪
  -> 前端频道元数据
  -> 观看页 SDK 获取当前播放时间
  -> 字幕适配层匹配附近字幕
  -> 本地摘要规则生成建议
  -> 用户确认
  -> localStorage 保存笔记
  -> 播放器 seekVideo 回跳
  -> Canvas 生成分享卡
```

### 5.3 摘要策略

首版不依赖外部模型。摘要按以下优先级生成：

1. 若保利威回放已有结构化大纲，使用与当前时间最接近的大纲段落。
2. 否则使用当前字幕和前后各一条字幕，提取核心句。
3. 字幕不可用时使用视频标题和当前时间生成可编辑占位摘要。

摘要必须允许用户修改，避免把自动摘要当作不可更正的事实。

## 6. 接口与安全

- AppSecret 只从环境变量读取。
- 服务端增加短时内存缓存，避免每次页面加载重复调用保利威。
- 前端请求只包含频道号和视频标识，不包含认证密钥。
- 服务端只返回频道名称、状态、观看地址、演示视频信息和可公开字幕。
- `.env*` 文件加入忽略规则；示例配置不包含真实值。
- 不在日志、错误响应或分享卡中输出密钥和推流信息。

## 7. 笔记数据模型

```ts
type Note = {
  id: string;
  channelId: string;
  videoId: string;
  time: number;
  duration: number;
  subtitle: string;
  summary: string;
  createdAt: string;
};
```

笔记按时间升序展示。时间格式为 `HH:MM:SS` 或 `MM:SS`。

## 8. 视觉方向

- 以保利威深色界面为基础，使用近黑背景、暖白文本和品牌蓝绿色强调色。
- 秒记按钮使用高对比胶囊造型，避免遮挡播放器控制栏。
- 笔记抽屉采用轻量半透明层、明确的时间轴和清晰卡片层级。
- 分享卡沿用产品界面语言，不复制海报的液态金属视觉，重点是让笔记内容成为视觉主体。

## 9. 错误处理

- 保利威接口失败时，前端进入明确标注的“演示内容”模式，保证参赛演示可继续。
- 播放器初始化失败时，提供频道直达链接和重试按钮。
- 本地存储不可用时，降级为当前页面内存存储并告知用户。
- 分享卡二维码生成失败时，保留文字下载并提示回看入口。
- 跳转时间超出视频时长时，限制到有效范围并提示。

## 10. 测试与验收

### 自动测试

- 保利威签名参数排序和 MD5 生成。
- 按当前时间查找最近字幕。
- 摘要降级顺序。
- 笔记新增、排序、删除和持久化。
- 时间格式化与边界值。
- 跳转秒数限制。

### 人工验收

- 在桌面浏览器打开真实频道并正常初始化播放器。
- 在视频任意时间点击秒记。
- 保存后刷新页面，笔记仍存在。
- 点击笔记可回到原时间点，误差不超过 1 秒。
- 分享卡可下载、二维码可识别并回到对应内容。
- 手机尺寸下按钮、抽屉和播放器控制可正常使用。
- 浏览器网络面板和打包产物中不存在 AppSecret。

## 11. 交付门槛

满足以下条件才可称为参赛版完成：

- 至少使用一个真实保利威频道和一个真实回放资源。
- 核心闭环可以从页面加载开始，无手动改代码、无开发者工具注入地完成。
- AppSecret 不进入前端。
- 60 秒演示脚本能够连续跑通至少两次。
