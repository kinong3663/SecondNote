# 秒记卡 · 接口与函数说明

> 给「要接着改这套代码」的人看：每个平台接口怎么调、签名怎么算、封装成了哪个函数、参数和返回是什么。
> 所有函数名与文件路径都能在仓库里对上，可直接搜索。

## 0. 一页调用链

```
浏览器（React，学生端 /）
   │  点「记一下」
   ├─ suggestSummary(cues, currentTime, title)      字幕 → 一句摘要
   ├─ saveNote(localStorage, note)                  本地主存储
   └─ reportNote(note) ──POST /api/notes──▶ Express(8787)
                                                └─ appendNote(note) → work/notes/<频道>/<videoKey>.jsonl

浏览器（教师端 /teacher）
   └─ GET /api/teacher/:videoKey ──▶ buildTeacherPayload(videoKey, channelId)
                                        ├─ listNotes(channelId, videoKey)
                                        ├─ fetchVodVideo(vid, {userid, secretkey})
                                        └─ aggregate({notes, chapters, ...}) → report

   └─ POST /api/teacher/:videoKey/summary ──▶ generateSummary({report, cards, videoKey})
                                        ├─ buildEvidence(report, cards)
                                        ├─ chatJson({system, user})       ← 模型 API
                                        ├─ validateOutput(data, evidence) ← 数字白名单
                                        └─ work/summaries/<videoKey>.json
```

密钥全部只在 Node 进程里；浏览器只拿到注入的 `channelId` 与 `videoKey`。

## 2. 保利威直播 Open API（MD5 签名）

### 2.1 签名函数

```js
// server/polyv.mjs
export function buildPolyvSign(params, appSecret) {
  const raw = Object.keys(params)
    .filter((key) => params[key] !== '' && params[key] != null)
    .sort()                                   // 按 key 字典序
    .map((key) => `${key}${params[key]}`)     // k+v 直接相连，没有分隔符
    .join('');
  return createHash('md5')
    .update(`${appSecret}${raw}${appSecret}`, 'utf8')  // 前后各加一次 secret
    .digest('hex')
    .toUpperCase();
}
```

要点：**k+v、无分隔符、前后都加 appSecret、MD5 大写**。业务参数之外必须带 `appId` 与 `timestamp`（毫秒）。

### 2.2 统一请求函数

```js
polyvGet(path, credentials, businessParams)   // server/polyv.mjs，私有
// 内部：createSignedParams() 补 appId/timestamp/sign → new URL(path, 'https://api.polyv.net') → fetch
// 成功判定：data.code === 200，否则抛 Error(data.message)
```

### 2.3 四个接口与封装

| 封装函数 | 接口 | 必填业务参数 | 用到返回里的什么 |
|---|---|---|---|
| `fetchChannelBundle(channelId, credentials, requestedSource, requestedVideoId)` | 下面四个一起发（`Promise.all`） | `channelId` | 组合成 `{channel, videos, source}` |
| 同上内部 | `GET /live/v4/channel/basic/get` | `channelId` | `data.name / watchStatus / watchUrl` |
| `fetchRecordFiles(channelId, credentials)` | `GET /live/v4/channel/record-file/list` | `channelId, pageNumber, pageSize` | `data.contents[]`：`fileId / channelSessionId / name / duration / watchUrl`、`subtitleList[0].srtUrl`、`outline.outlineUrl`、`outline.status` |
| 同上内部 | `GET /live/v3/user/playback/list` | `channelId, page, pageSize, listType(playback\|vod), order` | 回放 / 暂存列表 |
| 同上内部 | `GET /live/v4/channel/playback/list` | `channelIds` | `data[].origin`（vod / record）、`videoList` |

调用示例：

```js
import { fetchChannelBundle } from './polyv.mjs';

const bundle = await fetchChannelBundle('4711207', { appId, appSecret }, 'vod', '');
// bundle.channel → { channelId, name, videoKey: 'vod:xxx', duration, ... }
// bundle.videos  → [{ videoId, sourceType, title, duration, firstImage, watchUrl }]
```

失败表现：HTTP 非 200 抛 `Polyv API returned HTTP xxx`；`code !== 200` 抛平台 message（常见是 `sign` 或 `timestamp` 过期）。

## 3. 保利威点播 Open API（SHA1 签名）

### 3.1 签名函数

```js
// server/vod.mjs 与 server/subtitles.mjs 里各有一份（内容相同）
function vodSign(params, secretkey) {
  const raw = Object.keys(params)
    .filter((key) => params[key] !== '' && params[key] != null)
    .sort()
    .map((key) => `${key}=${params[key]}`)    // 这里是 k=v
    .join('&');                               // 用 & 连接
  return createHash('sha1')
    .update(`${raw}${secretkey}`, 'utf8')     // 末尾直接接 secretkey，没有 &
    .digest('hex')
    .toUpperCase();
}
```

与直播的差别（很容易写错）：

| | 直播 | 点播 |
|---|---|---|
| 摘要算法 | MD5 | SHA1 |
| 参数拼接 | `k` + `v` 相连 | `k=v`，`&` 连接 |
| secret 位置 | 前后各一次 | 只在末尾，**不加 `&`** |
| 必须带的参数 | `appId`、`timestamp` | `userid`、`ptime`（毫秒） |

### 3.2 统一请求函数

```js
vodGet(path, business, userid, secretkey)   // server/vod.mjs，私有
// params = { ...business, userid, ptime: String(Date.now()) }
// params.sign = vodSign(params, secretkey)
// URL = https://api.polyv.net + path，参数走 query
```

### 3.3 两个接口与封装

| 封装函数 | 接口 | 入参 | 返回 / 用途 |
|---|---|---|---|
| `fetchVodVideos({ userid, secretkey, pageSize = 50, title = '' })` | `GET /v2/video/search-videos` | `filters=basicInfo,transcodeInfo`、`page`、`pageSize`、`sort=creationTimeDesc`、可选 `title` | `[{ vid, title, duration, cover, creationTime, playUrl }]`；**5 分钟内存缓存** `listCache` |
| `fetchVodVideo(vid, { userid, secretkey })` | 同上（`title=vid` 再精确匹配） | `vid` | 单条 `{ vid, title, duration, cover, playUrl }` |
| `fetchVodSubtitleCues(vid, userid, secretkey)` | `GET /v2/video/{userid}/srt/list` | `vid` | `{ cues, srtUrl, name }`；取 `data.srts[0].url` 再交给 `fetchSubtitleCues()` 解析 |

直链是怎么取的：

```js
// server/vod.mjs
const pickPlayUrl = (item) => {
  const infos = item.transcodeInfos ?? [];
  const playable = infos.find((info) => info.status === 'normal' && info.playUrl);
  return { playUrl: playable?.playUrl ?? '' };
};
```

调用示例：

```js
const vods = await fetchVodVideos({ userid, secretkey, pageSize: 50 });
const first = vods[0];                 // { vid, title, duration, playUrl }
const { cues } = await fetchVodSubtitleCues(first.vid, userid, secretkey);
```

踩过的坑：

- 路径是 **`video` 单数**，且 `userid` 在路径上：`/v2/video/{userid}/srt/list`。
- `userid` 必须计入签名参数，否则一律 404。
- SHA1 原文末尾**不能**再加 `&`，加了就是 404。

## 4. 平台静态资源（CDN，不需要签名）

| 函数 | 入参 | 做什么 |
|---|---|---|
| `fetchSubtitleCues(srtUrl, key)` | SRT 直链、缓存 key | 下载 → `parseSrt()` → `cues[]`，写 `work/subtitles/srt-<key>.json` |
| `parseSrt(text)` | SRT 文本 | 解析成 `[{ start, end, text }]`，去 BOM、容错 `,`/`.` 毫秒 |
| `fetchOutlineChapters(outlineUrl, key)` | 大纲 JSON 直链 | `data.outline?.outlineContent ?? data.outlineContent` → `[{ title, start, end, startIndex, endIndex, summary, keyword }]` |
| `parseHms(value)` | `"00:05:53.000"` | 秒数（章节时间转换） |

点播 mp4 直链不走函数：`/api/channel/:id` 把它放进 `videos[].mediaUrl`，前端直接

```tsx

const useNativePlayer = Boolean(video.mediaUrl);
<video ref={nativeVideoRef} src={video.mediaUrl} />   // 206 + CORS *
```

## 5. 观看 SDK：`@polyv/live-watch-sdk`

只在**没有直链**时启用（`useNativePlayer === false`）。函数调用顺序：

```ts
// src/components/PlayerStage.tsx
const sdk = await import('@polyv/live-watch-sdk');
const core = sdk.createWatchCore(
  { channelId, vid: video.videoId, playbackOrigin: video.sourceType },
  { multiEnable: true },
);
await core.setup();
if (!core.auth.isAuthorized()) {
  const result = await core.auth.verifyNoneAuth();   // 匿名观看校验
  if (!result.success) throw new Error(`…${result.failReason}`);
  await core.setup();
}
await core.connect();
```

| 函数 | 作用 | 我们是否用 |
|---|---|---|
| `createWatchCore(config, options)` | 创建内核；`multiEnable` 支持多视频 | 用（仅回退路径） |
| `core.setup()` | 初始化（授权、播放器） | 用 |
| `core.auth.isAuthorized()` | 是否已有观看凭证 | 用 |
| `core.auth.verifyNoneAuth()` | 匿名观看校验，返回 `{ success, failReason }` | 用；**点播场景恒失败** |
| `core.connect()` | 连频道、拿播放数据 | 用 |
| `core.playback.getPlaybackTargetById({ playbackId })` | 按视频 ID 取播放目标 | 包装成 `resolvePlaybackTarget()` |
| `player.seekVideo(time)` | 跳转到指定秒 | 包装成 `seekSafely()` / `seekWhenReady()` |

为什么点播不走它：该频道 `authSetting.authSettings[0] = { authType: "phone" }`，匿名 `verifyNoneAuth()` 返回 `failReason: "Unknown"`；点播视频也没挂进频道播放列表。于是改成「直链 + 原生 `<video>`」，SDK 代码留作回退。

## 6. 模型 API（OpenAI 兼容）

### 6.1 端点选择

```js
// server/llm.mjs
resolveProvider()  // → { name: 'deepseek' | 'dashscope' | 'custom' | 'none', baseUrl, model, key }
describeProvider() // → { name, model, ready }   给前端显示「AI · qwen-plus」那枚标签
```

| provider | baseUrl | 默认模型 |
|---|---|---|
| `deepseek` | `https://api.deepseek.com` | `deepseek-chat` |
| `dashscope` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus`（当前实际运行） |
| `custom` | `LLM_BASE_URL` | `LLM_MODEL` |

### 6.2 唯一调用函数

```js
chatJson({ system, user, temperature = 0.2 })
// POST `${baseUrl}/chat/completions`，Authorization: Bearer <key>
// 先带 response_format: { type: 'json_object' }；失败则去掉重试，再从正文里截 {} 解析
// 返回 { data, model, provider, usage }
```

```js
const { data, model, usage } = await chatJson({
  system: SYSTEM,      // 五条硬约束：只引输入里的数字、不复述、动词开头、样本少要说明、不要营销腔
  user: `以下是本课的规则引擎证据（JSON）：\n${JSON.stringify(evidence)}\n\n请按系统提示输出 JSON。`,
});
// data = { verdict, findings: { <id>: { judgment, action } }, nextActions: [...] }
```

`SYSTEM` 里锁死了输出结构（`server/summary.mjs` 顶部），模型只能填这三个字段。

## 7. AI 复盘这条链（函数级）

| 函数 | 入参 | 出参 / 行为 |
|---|---|---|
| `buildEvidence(report, cards)` | 聚合报告 + 原始卡片 | 只放事实：课程规模、类型分布、热点（含 3 条样本）、诊断清单、最近 12 张卡 |
| `collectNumbers(value, out)` | 任意 JSON | 递归收集所有数字，得到「允许出现的数字集合」 |
| `validateOutput(data, evidence)` | 模型输出 | 返回**越界数字数组**；非空即判为编造 |
| `readSummary(videoKey)` | `vod:xxx` | 读 `work/summaries/<key>.json`，没有返回 `null` |
| `generateSummary({ report, cards, videoKey, force })` | 同上 | `{ ok, cached, summary, provider }`；失败返回 `code`：`no-provider` / `llm-error` / `fabricated-number` |

```js
const result = await generateSummary({ report, cards, videoKey, force: false });
if (!result.ok) {
  if (result.code === 'fabricated-number') { /* 模型编了数字，前端退回规则模板 */ }
}
```

## 8. 聚合引擎

```js
aggregate({ notes, chapters = [], durationSec, title = '', videoKey = '', sessionId = null, jumpUrl = null })
```

`report` 的关键字段（教师端与 AI 都吃这一份）：

```
scale:      { cards, viewers, perViewer, perMin, durationSec, byType }
buckets:    2 分钟 × 5 类型的格子
hotspots:   [{ id, t0, t1, cards, ratio, chapter, byType, samples[] }]
findings:   [{ id, level, title, t0, t1, judgment, action, evidence[] }]
reliability:{ level, reason }        // 卡片 < 12 张 → low sample
verdict / nextActions               // 规则模板兜底文案
```

## 12. 报错对照表

| 现象 | 原因 | 改哪里 |
|---|---|---|
| 点播接口 404 | `userid` 没进签名；或 SHA1 末尾多加了 `&`；或路径写成 `videos` 复数 | `vodSign()` 的拼接 |
| 直播接口 `code !== 200`，message 提到 sign | `timestamp` 过期（>5 分钟）或漏了业务参数 | `createSignedParams()` |
| 播放器提示「没能连上…failReason: Unknown」 | 频道开了观看条件（`authType: phone`），或视频没进频道播放列表 | 后台「频道设置 → 观看条件 / 点播列表」，或改用直链 |
| 分享卡二维码扫开停在首页 | `?t=` 参数丢了 | `buildInterpolatedShareUrl()` |
| 点「用 AI 生成解读」返回 422 `fabricated-number` | 模型写了证据外的数字 | 看 `reason` 里列出的数字，重试或改 prompt |
| AI 按钮不出现 / 显示「未配置模型 key」 | `LLM_API_KEY` 没进进程环境 | `.env.local` + 重启 |
| 教师端热力图很空、提示样本少 | 卡片 < 12 张 | `node scripts/seed-notes.mjs` 灌 8 张再操作 |
| `/api/notes` 400 | `videoKey` 不是 `来源:视频ID` 格式 | 前端传 `vod:<vid>` |
