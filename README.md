# 秒记卡 Second Note

秒记卡是嵌入保利威定制观看页的学习辅助工具。观众在直播或回放中点击“记一下”，系统保存当前时间、附近字幕和可编辑摘要；之后可以从笔记列表回到原画面，并导出一张带回看二维码的分享卡。

## 技术结构

- React 19 + TypeScript + Vite
- 保利威官方 `@polyv/live-watch-sdk`
- Node.js + Express 服务端签名代理
- `localStorage` 本地笔记持久化
- Canvas PNG 分享卡和 QR 二维码
- 本地 `faster-whisper` 视频音轨识别服务
- Vitest 单元测试

## 环境要求

- Node.js 20.19 或更高版本
- 可访问保利威 Open API
- 已配置观看页自定义域名的部署环境

## 本地启动

安装依赖：

```powershell
npm install
python -m pip install -r requirements-asr.txt
```

在 `.env.local` 中配置服务端密钥：

```dotenv
POLYV_APP_ID=你的应用ID
POLYV_APP_SECRET=你的应用密钥
POLYV_DEMO_CHANNEL_ID=8569582
```

构建并启动：

```powershell
npm run demo
```

打开 `http://127.0.0.1:8787`。

如果没有配置保利威密钥，应用仍会启动，但会明确显示“演示数据”。AppSecret 只在服务端使用，禁止改为 `VITE_` 环境变量。

## 常用命令

```powershell
npm run dev       # Vite 开发服务和 API 代理
npm test          # 运行全部单元测试
npm run build     # 类型检查并生成 dist

```

## 演示内容

默认频道：

```text
频道号：8569582
```

选择器会从保利威实时读取当前频道的“直播暂存、回放列表、点播列表”。演示时该频道返回 2 条直播暂存和 5 条已配置点播；回放列表为空时显示明确的空状态。

平台没有发布字幕时，界面不会再用示意文本冒充视频字幕。服务端提供 `POST /api/transcript`，可对允许的保利威媒体地址运行本地 Whisper，并将带时间戳的结果缓存到 `work/transcripts`。缓存存在时页面显示“AI 字幕”，否则明确显示“暂无字幕”。

## 核心流程

1. 点击播放器顶部的视频名称，在“直播暂存 / 回放列表 / 点播列表”三个分类间切换并选择视频。
2. 播放保利威回放。
3. 点击播放器右下角的“记一下”。
4. 系统抓取当前秒数、附近字幕并生成可编辑摘要。
5. 保存后写入本地笔记列表。
6. 点击笔记时间戳，调用观看页 SDK 的 `seekVideo` 回跳。
7. 分享卡包含回看链接和二维码；链接使用 `t` 参数恢复播放位置。

切换视频时会更新 `source` 和视频 ID，重新初始化对应的 Polyv 播放模式，并按“来源类型 + 视频 ID”读取独立笔记。直播暂存使用保利威返回的原始录制播放地址，回放和点播使用官方观看页 SDK。后台新增或删除视频后，选择器中的分类数量会同步更新。

## 接入保利威观看页

本项目使用保利威推荐的官方观看页 SDK 进行定制。正式上线时需要在保利威直播后台的“开发设置 / 开发者信息”中加入部署域名，然后：

1. 将构建产物部署到已登记的 HTTPS 域名。
2. 通过观看页自定义菜单或独立观看入口链接到该页面。
3. 使用正式频道号替换默认频道。
4. 将演示字幕替换为平台字幕或业务方提供的逐字稿。
5. 如果启用本地识别，在生产环境安装 `requirements-asr.txt` 中的 Python 依赖。

## 安全说明

- `.env.local` 已被忽略，不会进入版本控制。
- 前端只接收裁剪后的频道名称、状态、观看地址和公开视频信息。
- 服务端不会返回 `appSecret`、频道口令或推流密钥。
- 首版没有登录和跨设备同步，清除浏览器数据会删除本地笔记。
